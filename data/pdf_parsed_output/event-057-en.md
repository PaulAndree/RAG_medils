First ARIADNA bilingual annotation workshop to resolve disagreements about unanswerable questions, temporal questions, equivalence across language versions and selection of minimally sufficient evidence.

Andrés Beltrán: We annotated an initial batch of eighty questions. Agreement is good for direct questions but lower for temporal and unanswerable cases.
Pablo Herrero: The main disagreement occurs when an answer exists in an old version but not in the current document.
Lucía Navarro: The question must include or imply a date. If it asks about the current procedure, an answer based only on a superseded version must be considered incorrect.
Tomás Leal: What if the current English version has not yet been published, but the Spanish version has?
Sergio Vidal: We must answer according to the corpus and date for each language. The absence of a translation does not turn the Spanish version into English evidence.
Mireia Soler: I propose recording three states: answerable with current evidence, answerable only historically and unanswerable within the requested scope.
Pablo Herrero: There is also disagreement about how much evidence to mark. Some annotators select the entire document, while others select one sentence.
Lucía Navarro: Minimal evidence must include every part required to justify the answer, but irrelevant content should not be selected.
Andrés Beltrán: We approve the three states and the minimally sufficient evidence rule. Parallel questions must preserve the same target fact, although available evidence may differ by language.
Tomás Leal: I will update the guide, and we will reannotate twenty disputed cases to measure improvement.
