Three quotations were received for expanding Atlas-2 storage. Quote A provides 48 TB usable capacity for EUR 14,800, with delivery in six weeks and a three-year warranty. Quote B offers 60 TB for EUR 17,950, delivery in four weeks, and a five-year warranty. Quote C includes 64 TB for EUR 16,900 but uses a controller model different from the installed system and requires an additional intervention.

Quote B has the highest cost per terabyte, although it shortens delivery time and extends the warranty. Quote C is competitive in capacity but introduces compatibility risk and an unquoted configuration cost. Quote A is compatible with the current system and sufficient for the eighteen-month forecast, although it leaves less room for new models.

The recommendation is to select quote A if the supplier confirms replacement drives within five working days. Nuria will verify compatibility, and Rosa will request the replacement clause. The purchase will be charged to the shared infrastructure cost centre.
