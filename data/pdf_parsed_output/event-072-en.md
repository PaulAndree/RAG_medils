Fourth bilingual annotation workshop to define criteria for relative dates, administrative acronyms, automatic reformulations and question maintenance when institutional documentation changes.

Andrés Beltrán: The robustness analysis showed that we need more precise rules for relative dates and acronyms.
Lucía Navarro: A question such as 'what is the limit this year?' depends on the query date. Annotation must store an explicit reference date even when it is not shown in the visible text.
Tomás Leal: We must also distinguish official acronyms from abbreviations created by users. 'HR' may be expanded safely, but 'committee' does not identify a specific unit.
Rosa Mena: Administration uses different acronyms for the same unit across documents. We should retain a catalogue with validity periods.
Pablo Herrero: The tool can record queryReferenceDate, detectedAcronyms and normalizedQuery. The annotator will approve or reject each reformulation.
Sergio Vidal: For maintenance, I propose that a question not be overwritten when a rule changes. A new version will be created, while the previous version retains its validity interval.
Lucía Navarro: Bilingual versions must be updated as a pair when the fact changes, even if their publication dates remain different.
Andrés Beltrán: How will we evaluate an incorrect reformulation?
Tomás Leal: As a system error, even if later retrieval happens to find the correct answer by chance.
Andrés Beltrán: We approve the hidden reference date, temporal acronym catalogue, human approval of reformulations and question versioning. The guide moves to version 1.2.
