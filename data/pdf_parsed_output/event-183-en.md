First NEXUS onboarding-improvement session to reduce access delays, clarify supervision responsibilities and create differentiated paths for staff, students, visitors and external collaborators.

Clara Ibáñez: We reviewed twelve recent arrivals. The average time to obtain all access was nine working days.
Pablo Herrero: The greatest delays involve identifying which repositories each role needs and who approves restricted data.
Nuria Castaño: I propose four onboarding profiles: employee, doctoral researcher, visitor and external collaborator. Each profile will have a default list of systems and training.
Sergio Vidal: Closed-evaluation access must never be included by default. It will be granted only through a specific request with an expiry date.
Yara Ben Salem: Visitors lack a clear guide covering insurance, workspace, temporary accounts and closure date. During my arrival, those steps came through different channels.
Alba Prieto: Doctoral onboarding should include a data plan, project repositories and training on versions and provenance.
Mateo Ruiz: It should also include a tools glossary. Several people confuse the data catalogue with the document repository.
Inés Ferrer: In projects involving sensitive data, privacy training must be completed before downloading or running any container.
Clara Ibáñez: What timing objective should we set?
Nuria Castaño: Basic access within two working days and specific access within five, provided the request is complete.
Pablo Herrero: I will create one form containing owner, project, dates, data level and system list.
Clara Ibáñez: We approve the four profiles, single form and two- and five-day objectives. A closure checklist will be mandatory for visitors and temporary contracts.
