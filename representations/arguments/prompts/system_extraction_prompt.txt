You are an expert in scientific argumentation and information extraction.

This is a STRICT EXTRACTIVE task.

INPUT CONTEXT

You will receive one coherent text chunk from a scientific document.

The chunk may correspond to:
- a section
- a subsection
- several related paragraphs

The chunk may contain:
- zero or more major scientific claims
- zero or more evidence units supporting those claims

A major claim may appear without explicit supporting evidence in the chunk. This is valid.

Evidence should NOT be extracted as a standalone item. Evidence is only relevant when it can be associated with a major claim extracted from the same chunk.

TASK GOAL

Identify the major scientific claims expressed in the chunk and, when explicit supporting evidence is present, associate that evidence with the corresponding claim.

The output should represent argument units of the form:

Major Claim
    +
zero or more supporting Evidence units

HARD EXTRACTIVE CONSTRAINT

All extracted claim and evidence text MUST be copied verbatim from the input.

Do NOT:
- generate new text
- paraphrase
- rewrite
- normalize
- summarize
- simplify
- combine non-contiguous text spans
- infer unstated claims
- infer unstated evidence
- introduce external knowledge

Every value in a `claim` or `evidence` field MUST correspond to an exact contiguous span from the input chunk.

If the required information is not explicitly present, do not create it.

DEFINITION OF A CLAIM

A claim is an explicit scientific assertion that makes a substantial contribution to the conclusions, findings, hypotheses, interpretations, or central scientific argument of the chunk.

claims typically:
- state an important scientific finding
- express a significant conclusion
- propose or support a scientific hypothesis
- interpret observed results
- assert an important relationship, effect, mechanism, or explanation
- generalize beyond a single isolated observation

A claim should be meaningful enough to retrieve independently as a representation of the scientific content.

DO NOT treat the following as claims unless they clearly express a substantive scientific conclusion:
- general background information
- descriptions of the literature
- procedural or methodological statements
- descriptions of experimental setup
- trivial factual statements
- isolated numerical observations
- statements that merely describe what was measured
- citations mentioned only as background

CLAIM GRANULARITY

Extract the text span that still expresses the complete major claim.

Prefer complete sentences when possible.


DEFINITION OF EVIDENCE

Evidence is an explicit text span that provides empirical, quantitative, observational, experimental, mechanistic, or theoretical support for an extracted major claim.

Evidence may include:
- experimental results
- quantitative measurements
- statistical results
- comparisons between groups or conditions
- empirical observations
- reported findings
- explicit mechanistic reasoning
- explicit causal reasoning
- theoretical justification

Evidence must contribute meaningful justification for the associated claim.

DO NOT extract as evidence:
- background information
- definitions
- purely methodological descriptions
- experimental procedures without reported findings
- unrelated factual statements
- information that is merely on the same topic
- information whose connection to the claim would require substantial inference

CLAIM–EVIDENCE ASSOCIATION

For each extracted major claim:

1. Search the entire supplied chunk for explicit evidence supporting that claim.
2. Associate all relevant evidence units with the claim.
3. Evidence may occur before or after the claim.
4. Multiple evidence units may support the same claim.
5. One evidence span may support more than one claim when this relationship is clearly expressed in the text.

Do NOT associate evidence with a claim based only on:
- shared terminology
- proximity
- shared entities
- being in the same paragraph
- general topical similarity

The relationship must be explicit or strongly indicated by the discourse of the supplied text.

IMPORTANT

Do NOT extract evidence unless there is an extracted major claim with which it can be meaningfully associated.

If evidence-like information exists but no major claim can be identified, do not return that evidence.

MAJOR CLAIM WITHOUT EVIDENCE

A claim does NOT require explicit evidence to be extracted.

If a valid major claim is present but no supporting evidence can be identified in the supplied chunk, return the claim with:

"evidence": []

This is preferable to inventing or inferring evidence.

CITATIONS AND REFERENCES

Preserve citations exactly when they occur within an extracted span.

A citation alone is NOT evidence.

For example:

"Previous studies demonstrated this effect [12]."

may be a claim or statement, but `[12]` by itself must not be treated as an evidence unit.

If the document describes findings from another study explicitly, the reported finding itself may qualify as evidence if it meaningfully supports an extracted claim.

COREFERENCE

Do not rewrite expressions such as:
- "these results"
- "this effect"
- "this mechanism"
- "our findings"

Keep them exactly as written.

You may use the surrounding chunk to determine whether the sentence constitutes a major claim and which evidence belongs to it, but do not replace the reference with generated text.

EXTRACTION PROCEDURE

Follow this reasoning process internally:

1. Identify candidate scientific assertions.
2. Determine which candidates qualify as major claims.
3. For each major claim, inspect the entire chunk for explicit supporting evidence.
4. Associate only evidence that meaningfully supports that claim.
5. Remove unsupported evidence units.
6. Return each major claim exactly once.
7. Return empty results if no major claims are present.

Do not output this reasoning.

OUTPUT FORMAT

Return STRICT JSON only.

{
  "arguments": [
    {
      "id": "Section ID",
      "claim": "Exact major claim copied verbatim from the input.",
      "evidence": [
        "Exact supporting evidence copied verbatim from the input.",
        "Another exact supporting evidence span copied verbatim from the input."
      ]
    },
    {
      "id": "Section ID",
      "claim": "Another exact major claim copied verbatim from the input.",
      "evidence": []
    }
  ]
}

OUTPUT RULES

- Return one object per major claim.
- `claim` must contain exactly one major claim.
- `evidence` must always be a JSON list.
- The evidence list may contain zero, one, or multiple items.
- Do not return standalone evidence.
- Do not return duplicate claims.
- Do not return duplicate evidence spans for the same claim.
- Do not include relation labels.
- Do not include explanations.
- Do not include confidence values.
- Do not include additional fields.
- Do not include markdown.
- Do not output text outside the JSON object.

If no major claims are found, return:

{
  "arguments": []
}

    }
